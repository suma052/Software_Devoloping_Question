# Course Code: ICT 3107 & ICT 3108
## Course Title: Software Engineering
### Assignment: Question Paper Development on Software Design (OBE & BNQF Standard)

**Time:** 1 Hour  
**Total Marks:** 40  
**Reference Material:** `SoftEng-Design.pdf`
---

### Course Outcomes (COs) Mapping Reference

* **CO1:** Understand the fundamental concepts, principles, and modularity of software design.
* **CO2:** Evaluate software design quality and complexity using standard Object-Oriented (CK) metrics.
* **CO3:** Analyze and compare different software architectural styles and Enterprise Application Architecture (EAA) patterns.
* **CO4:** Explain the intent, structure, and trade-offs of Gang of Four (GoF) object-oriented design patterns.
* **CO5:** Apply fundamental User Interface (UI) design principles, modalities, and presentation guidelines.

---### Question Paper (Total Marks: 40)

#### Question 1: Design Fundamentals & Quality Metrics [Marks: 10]

* **(a)** Define Software Design. Explain the importance of modularity and decomposition in software design. `[Marks: 2] [Bloom's: Knowledge & Understanding] [CO1]`
* **(b)** What are Coupling and Cohesion? Why is low coupling and high cohesion desirable in software design? `[Marks: 2] [Bloom's: Understanding] [CO1]`
* **(c)** Define Coupling Between Object Classes (CBO). How is it measured? `[Marks: 2] [Bloom's: Knowledge] [CO2]`
* **(d)** Explain Lack of Cohesion of Methods (LCOM). What do the values of LCOM indicate about class cohesion? `[Marks: 2] [Bloom's: Understanding] [CO2]`
* **(e)** What is Weighted Methods per Class (WMC)? Explain how method complexity is measured using the McCabe approach. `[Marks: 2] [Bloom's: Understanding] [CO2]`

---#### Question 2: Software Architecture & EAA Patterns [Marks: 10]

* **(a)** Define Software Architecture. What are the main elements of software architecture? `[Marks: 2] [Bloom's: Knowledge] [CO3]`
* **(b)** Explain the Layered Architecture and its basic structure. `[Marks: 2] [Bloom's: Understanding] [CO3]`
* **(c)** Differentiate between Pipes and Filters and Event-Based architectural styles. `[Marks: 2] [Bloom's: Understanding] [CO3]`
* **(d)** Explain the three main components of Model-View-Controller (MVC) architecture. `[Marks: 2] [Bloom's: Understanding] [CO3]`
* **(e)** Compare Single Table Inheritance and Class Table Inheritance in Enterprise Application Architecture. Mention one advantage and one disadvantage of each. `[Marks: 2] [Bloom's: Understanding] [CO3]`

---#### Question 3: Gang of Four (GoF) Design Patterns [Marks: 10]

* **(a)** What are Design Patterns? List the three classifications of GoF patterns with two examples from each category. `[Marks: 2] [Bloom's: Knowledge] [CO4]`
* **(b)** Explain the intent and structure of the Adapter Design Pattern. `[Marks: 2] [Bloom's: Understanding] [CO4]`
* **(c)** What is the Decorator Design Pattern? Explain one benefit of using this pattern. `[Marks: 2] [Bloom's: Understanding] [CO4]`
* **(d)** Describe how the Observer Design Pattern maintains communication between a Subject and multiple Observers. `[Marks: 2] [Bloom's: Understanding] [CO4]`
* **(e)** Explain the intent of the Strategy Design Pattern. Mention two benefits of this pattern. `[Marks: 2] [Bloom's: Understanding] [CO4]`

---#### Question 4: Presentation Logic & User Interface (UI) Design [Marks: 10]

* **(a)** Define Page Controller and Front Controller presentation logic patterns. `[Marks: 2] [Bloom's: Knowledge] [CO3]`
* **(b)** Identify and explain any four fundamental UI Design Principles. `[Marks: 2] [Bloom's: Understanding] [CO5]`
* **(c)** What are UI Modalities? Explain Form Fill-in and Command Language. `[Marks: 2] [Bloom's: Understanding] [CO5]`
* **(d)** Explain Recoverability and User Guidance in UI design. `[Marks: 2] [Bloom's: Understanding] [CO5]`
* **(e)** Why should a user interface support users with different capabilities, including color blindness and poor eyesight? `[Marks: 2] [Bloom's: Understanding] [CO5]`
